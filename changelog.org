#+TITLE: Changelog

* 1.1.0
- Grammar guard: a missing tree-sitter grammar now signals a clear, actionable error naming the grammar, instead of an opaque dlopen failure
- New command: =prisma-md-install-grammars= builds and installs the =markdown= and =markdown-inline= grammars using built-in recipes
- Batch test runs set =load-prefer-newer=, so stale byte-compiled files can no longer shadow current sources
- README documents grammar prerequisites, recovery, and the Emacs ABI caveat after major upgrades

* 1.0.0
- Markdown (GFM) <-> Org bidirectional conversion
- Intermediary AST model with positioned nodes
- Tree-sitter parser for Markdown (dual block + inline grammars)
- PEG parser engine with packrat memoization
- Org parser (regex blocks, hand-written inline with emphasis boundary rules)
- Structural AST diff (content-hash matching)
- Patch engine (byte-range replacement, reverse-order application, trailing newline preservation)
- Buffer manager: =prisma-convert=, =prisma-commit=, =prisma-cancel=, =prisma-diff=
- =prisma-mirror-mode= with header-line showing keybindings
- Same-window seamless transitions with AST-based cursor position mapping
- Passthrough for format-specific constructs (tables, images, unrecognized markup)
- Concurrent source modification detection
