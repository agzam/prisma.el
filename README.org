#+TITLE: El Prisma

Same content, different spectrum.

* What

El Prisma converts buffer content between formats, creating mirror buffers for editing in your preferred format. Edits are surgically patched back into the source - untouched regions remain byte-identical.

Currently supported: Markdown (GFM) <-> Org

* Why

Pandoc's conversion is lossy and opinionated - it normalizes formatting and drops metadata. El Prisma uses a positioned intermediary AST to track exactly what changed, then patches only the modified regions. Your formatting survives.

Format-specific constructs with no target equivalent pass through as literal text and round-trip verbatim.

* Usage

#+begin_src emacs-lisp
;; In a Markdown buffer:
M-x el-prisma-convert    ; opens Org mirror in same window

;; Edit freely in Org, then:
C-c C-c                  ; commit changes back to Markdown
C-c C-k                  ; cancel, discard mirror
C-c C-p C-d              ; preview diff
#+end_src

Works in both directions - invoke =el-prisma-convert= in an Org buffer to get a Markdown mirror.

* Prerequisites

Emacs 29.1+ with tree-sitter support. Compiled grammars for =markdown= and =markdown-inline= (from [[https://github.com/tree-sitter-grammars/tree-sitter-markdown][tree-sitter-grammars/tree-sitter-markdown]]).
